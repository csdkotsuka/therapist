# ① プラットフォーム管理者向け 運用・仕様マニュアル

本ドキュメントは、ヘルスケア＆ボディケア・オンデマンドプラットフォーム「CareHub」のプラットフォーム管理者（Admin）向け操作およびシステム仕様マニュアルです。

---

## 🎯 管理者の役割と権限

管理者（Admin）はプラットフォーム全体の健全な運営、信頼性の担保、および収益管理を司ります。

1. **セラピスト登録審査・パートナー管理**:
   - 新規登録されたセラピストの資格確認、本人確認を行い、プラットフォームへの公開（承認 / 停止）をコントロールします。
2. **全予約トランザクション監視**:
   - 出張・店舗の全予約ステータス（承認待ち、確定、完了、キャンセル）をリアルタイムで監視。
   - トラブル発生時の強制キャンセルおよび全額返金対応を行います。
3. **手数料率（Take Rate）設定**:
   - プラットフォーム利用料率（デフォルト: 20%）を動的に設定。新規予約から自動適用されます。
4. **レビューモデレーション**:
   - 不適切なレビューや誹謗中傷コメントを検閲・非表示化。
5. **全体KPIの可視化**:
   - 流通総額（GMV）、手数料売上、総予約数、登録セラピスト・顧客数をリアルタイム集計。

---

## 🖥 管理画面の主要機能と操作フロー

### 1. KPI・ダッシュボード
- **総流通額 (GMV)**: 確定・完了した予約の合計決済額。
- **プラットフォーム手数料収益**: GMV × 手数料率によって得られたプラットフォームの粗利。
- **予約ステータス構成**: 全予約に対する「承認待ち」「予約確定」「完了」「キャンセル」の割合をグラフ表示。

### 2. 全予約ステータス監視 (`/admin > 全予約`)
- 全トランザクションの予約番号、顧客名、セラピスト名、施術形態（出張/店舗）、日時、金額、手数料内訳を一覧化。
- **強制キャンセル機能**: 悪質なトラブルや緊急時に、管理者権限でステータスを `cancelled` に更新。

### 3. セラピスト・ユーザー審査 (`/admin > セラピスト審査`)
- セラピスト一覧と経歴・資格・住所・対応フラグを確認。
- **承認トグルスイッチ**: ワンクリックで「審査承認済み（公開中）」と「審査中/停止」を切り替え可能。

### 4. 手数料率・プラットフォーム設定 (`/admin > 手数料設定`)
- スライダー操作（5%〜40%）で手数料率を変更し「手数料率を保存」を押すと、即座にシステム全体に反映。

### 5. レビューモデレーション (`/admin > レビュー管理`)
- 顧客から投稿された全クチコミを監視。不適切な投稿の削除ボタン。
