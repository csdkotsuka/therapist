# ② セラピスト向け 運用・操作マニュアル

本ドキュメントは、ヘルスケア＆ボディケア・オンデマンドプラットフォーム「CareHub」に登録するセラピスト（理学療法士、エステティシャン、整体師、カイロプラクター等）向け操作マニュアルです。

---

## 🎯 セラピストの役割と業務フロー

セラピストは、出張（訪問施術）または店舗（ご来店）の予約を受け付け、顧客へ質の高いケアを提供します。

### 全体業務フロー
1. **予約リクエストの受信**: 顧客から希望日時・施術メニュー・出張先住所が届きます。
2. **承認・辞退の判断**: スケジュールを確認し、ワンタップで「承認」または「辞退」を選択。
3. **出張移動とGPS位置送信** (出張時):
   - 移動開始時に「GPS位置情報を送信」を押すことで、顧客の画面にリアルタイムで移動状況と到着予定時間（ETA）が表示されます。
4. **施術の実施**: 丁寧な問診・検査の上で施術を行います。
5. **施術完了報告**: 画面上で「施術完了を報告」ボタンを押すと、売上分配が確定。
6. **売上確認・振込受取**: Stripe Connect Express により、手数料引き落とし後の手取り報酬が銀行口座へ自動入金されます。

## 🖥 セラピスト画面の主要機能

### 1. 予約リクエスト一覧 (`/therapist > リクエスト`)
- **未対応リクエスト**: 顧客からの予約要望（メニュー、日時、出張先、手取り金額、顧客メモ）を確認。
  - 「承認して予約を確定」ボタン
  - 「辞退する」ボタン
- **確定済み予約**:
  - 「GPS位置情報を送信」ボタン（出張移動中に位置をブロードキャスト）
  - 「施術完了を報告」ボタン

### 2. シフト・出張エリア設定 (`/therapist > シフト・出張エリア`)
- **受付可能曜日**: 月〜日から自由に稼働曜日を選択。
- **受付時間帯**: 開始時刻・終了時刻（例: 09:00〜21:00）を設定。
- **出張対応可能半径スライダー**: 拠点から半径何kmまで出張可能かを設定（例: 15km）。

### 3. 施術メニュー管理 (`/therapist > 施術メニュー`)
- 新規メニュー登録（メニュー名、施術内容、料金、所要時間、カテゴリ）。
- いつでも料金や時間の変更が可能。

### 4. 売上・振込明細 (`/therapist > 売上明細`)
- 今月の総取扱高、手数料、純手取り額（振込可能残高）の確認。
- Stripe Express ダッシュボードへのダイレクトリンク。
