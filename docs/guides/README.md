# CareHub ガイド・マニュアル一覧

CareHub では、ロールごとに適切な権限と閲覧範囲を定めたマニュアルを用意しています。

| マニュアル | 対象者 | 権限・リンク関係 |
| :--- | :--- | :--- |
| [① 管理者向け 運用マニュアル](./01_admin_guide.md) | プラットフォーム管理者 | **②セラピスト向け、③顧客向けへアクセス可** |
| [② セラピスト向け 運用マニュアル](./02_therapist_guide.md) | 登録施術者・パートナー | **③顧客向けへアクセス可**（管理者向けへのリンクなし） |
| [③ 顧客向け ご利用ガイド](./03_customer_guide.md) | 一般顧客・利用者 | **他のマニュアルへのリンクなし**（安心の顧客専用設計） |

Webブラウザ上で閲覧する場合は、アプリ内の以下のURLからもアクセスできます：
- 管理者向けページ: `/guide/admin`
- セラピスト向けページ: `/guide/therapist`
- 顧客向けページ: `/guide/customer`
